# OwnTest

Android-приложение для создания и прохождения тестов: любой пользователь может составить свой тест, опубликовать его и проверить ответы других участников.

## О проекте

OwnTest — платформа пользовательских тестов. Автор создаёт тест с вопросами двух типов: с выбором ответа и с развёрнутым текстовым ответом. Вопросы с выбором проверяются автоматически, а текстовые ответы автор проверяет вручную и начисляет баллы. Участники проходят тесты, оценивают их и видят свою историю прохождений.

## Возможности

- **Конструктор тестов**: название, описание, иконка, уровень сложности, количество вариантов ответа.
- **Два типа вопросов**: с выбором правильного варианта и с текстовым ответом, у каждого вопроса своё количество баллов.
- **Редактирование** уже созданных тестов и вопросов.
- **Прохождение тестов** с возможностью разрешить или запретить повторные попытки.
- **Ручная проверка** текстовых ответов автором теста.
- **Рейтинг тестов** и счётчик прохождений.
- **Уведомления** о прохождении теста и о проверке ответов.
- **Профиль**: созданные и пройденные тесты, уникальный никнейм, аватар, просмотр профилей других пользователей.
- Регистрация, вход и восстановление пароля.

## Технологии

- Java, Android SDK (minSdk 27, targetSdk 36), ViewBinding, Material Components
- Firebase Authentication, Firebase Realtime Database, Firebase Analytics
- Cloudinary для хранения изображений
- Glide, ViewPager2, SwipeRefreshLayout

## Структура

```
app/src/main/java/com/example/owntest/
  activities/   вход, регистрация, восстановление пароля, главный экран
  fragments/    создание, редактирование, прохождение и проверка тестов, профиль, уведомления
  managers/     работа с Firebase и Cloudinary
  models/       тест, вопрос, ответ, прохождение, пользователь, уведомление
  adapters/     списки тестов и уведомлений
```

## Запуск

1. Откройте проект в Android Studio. Чтобы подключить свой проект Firebase, замените `app/google-services.json`.
2. Укажите ключи Cloudinary в `managers/CloudinaryManager.java` вместо `YOUR_CLOUDINARY_API_KEY` и `YOUR_CLOUDINARY_API_SECRET`.
